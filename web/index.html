초파리 2족 보행 학습

초파리 전신 모델(flybody)이 평소 6족 자세에서 스스로 일어나 뒷다리 두 개로 목표 지점까지 걸어가도록 강화학습합니다. 관절은 전부 자유롭고, "2족"은 보상으로만 유도합니다.

▶ 브라우저 실시간 시뮬레이터 열기

물리(MuJoCo WASM)와 정책 추론이 브라우저 안에서 돕니다. 정책은 학습 서버에서 2분마다 자동 갱신됩니다.

학습 진행 (자동 갱신)

-학습 스텝
-몸통이 바닥에 닿은 시간 비율
-2족 서기 비율 (4초 중)
-에피소드당 목표 도달
-학습 속도 (스텝/초)

체크포인트마다 CPU에서 3초 × 4에피소드(6족 시작 2, 뒷다리 서기 1, 낙하 1)를 돌린 결과입니다. 파랑: 몸통 접촉 비율, 초록: 2족 서기 비율, 주황: 목표 도달 수.

발전 타임랩스

체크포인트마다 자동 렌더한 3초 클립입니다(왼쪽: 6족 자세 시작, 오른쪽: 뒷다리 서기 시작). 최신이 위입니다.

단계

완료GPU 물리(MuJoCo Warp) 검증, 전신 모델 정리(입·더듬이·평형곤만 고정), 6족 자세와 뒷다리 서기 자세 확보
완료브라우저 뷰어(물리 + 정책 추론), 학습 체크포인트 자동 배포
완료설계 검증: 사족 로봇 2족 보행·일어서기·목표 도달 문헌 15편과 공개 코드 비교 후 v2 설계 확정
진행자동 조종 학습: 1,500만 스텝 단위로 평가 지표를 읽어 정체하면 서기 유도 강화 → 서기 보조력(HoST 2025 방식) 순으로 설정을 스스로 바꾸고, 서기가 되면 보조력을 0까지 줄입니다. 목표 도달이 에피소드당 2회를 넘으면 완료.
대기평가 영상·성공률 집계

설계 근거 (조사 결과 요약)

세 갈래로 문헌과 공개 코드를 조사해 제 초안(v1)을 검증했고, 어긋난 부분을 v2에서 고쳤습니다.

1. 사족 로봇의 2족 보행 학습 (TumblerNet npj Robotics 2025, Go2 분포형 PPO 2025, CyberDog2 2023, A1 AMP 2024, Mini Cheetah 2022)

  • 다섯 편 모두 행동을 기본 자세 기준 관절 변화량으로 두고 50Hz PD 제어를 씁니다. 저도 같은 방식입니다.
  • "2족"은 앞발 접촉력 벌점(TumblerNet: 앞발 접촉력 −0.03, 충돌 −1.0)이나 앞다리 충돌 시 종료(CyberDog2: 시작 30스텝 유예 후)로 강제합니다. 전진 추적 보상은 몸이 선 뒤에만 켭니다.
  • 보고된 편법: "뒷다리 종아리로 앉아 버티기", "앞다리 꼬기", "발 살짝만 들기". → v2는 2족 판정에 몸통 높이 0.16cm 이상·몸통 비접촉을 추가했습니다.

2. 넘어진 뒤 일어서기 (MuJoCo Playground Go1 Getup, ANYmal 2019, Learning to Get Up 2022, HoST 2025, 사족 복구 2024)

  • 다섯 편 모두 넘어져도 종료하지 않고 시간 제한만 둡니다. 자세 보상은 몸이 세워졌을 때만 줍니다. 시작 상태는 공중에서 무작위 방향으로 떨어뜨린 뒤 0.5~2초 안정화한 상태를 섞습니다.
  • → v1의 "넘어지면 종료"는 배가 바닥에 닿는 순간 끝나서 일어서기 탐색을 막았습니다. v2는 종료를 없애고 몸통 접촉 −1.0 벌점으로 바꿨으며, 에피소드의 30%를 낙하 상태에서 시작합니다.

3. 목표 도달 보상과 고주파 제어 PPO (ETH 2022, ANYmal Parkour 2024, Isaac Lab 내비게이션, Reda 2020, Kalyanakrishnan 2021)

  • 목표까지 거리가 줄어드는 만큼 주는 진행 보상은 표준이지만, "마지막에 몰아서 뛰기", "기다리기" 편법이 보고돼 있고 ETH는 정지 벌점으로 막습니다. → v2에 정지 벌점 추가.
  • 제어 주파수가 너무 높으면 학습이 나빠지고, 할인율보다 액션 반복이 효과적이라는 결과가 있습니다. 유효 지평선은 1/(1−γ) 스텝이라 γ = 1 − Δt/T로 잡습니다. → 제어 주기 2ms→4ms, γ 0.99→0.996(지평선 약 1초). flybody 원논문은 2ms 제어에 할인율 0.99(지평선 0.2초)를 썼습니다.

4. 뒤집힘에서 일어서기 (JHU Terradynamics Lab 바퀴 자기복원 연구 2019, npj Robotics 2024)

  • 날개 있는 곤충은 날개를 비대칭으로 펴 바닥을 밀어 몸을 기울이고 굴러서 일어납니다. 구르기가 에너지 장벽을 40% 낮춥니다. 날개 없는 종은 몸을 활처럼 굽혀 무게중심을 올린 뒤 구르고 다리를 밑에 끼웁니다.
  • → 넘어진 동안은 날개 접기 벌점을 해제하고, 뒤집힌 상태에서도 기울기가 있는 자세 보상(중력 방향 코사인)을 추가했습니다. 일어서기 집중 훈련(넘어진 시작 100%, 보조력 0)을 별도 단계로 둡니다.

관측을 센서로만 제한한 이유

시뮬레이터 내부 좌표(몸통 절대 높이, 목표 좌표, 기하 접촉 판정)를 정책 입력에서 뺐습니다. 실제 로봇이 가질 수 있는 것만 씁니다: 관절 엔코더, IMU(자이로·가속도·중력 방향), 발끝 힘·촉각 센서, 그리고 눈이 보는 목표(머리 기준 방위·고도·각크기·가시 여부, 초파리 겹눈의 뒤쪽 약 50° 사각 반영).
